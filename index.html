Como funciona

1. Autentique

Entre com sua conta GitHub via OAuth. Seus dados são protegidos por JWT e cookie httponly.

2. Cadastre um repositório

Informe o owner e o nome do repositório — público ou privado — que deseja analisar.

3. Obtenha o relatório

A API coleta commits, PRs e issues, processa métricas Lean e detecta desperdícios automaticamente.
